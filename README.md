# 🌾 AgriIoT-ABSA

Dashboard **Aspect-Based Sentiment Analysis (ABSA)** untuk komentar YouTube
tentang **IoT di Pertanian** menggunakan **IndoBERT**.

Dikembangkan dari tesis Hanif Zaidan Sinaga (Universitas Pamulang, 2026):
*Perbandingan Kinerja IndoBERT dan IndoRoBERTa dalam ABSA pada Komentar
YouTube tentang Internet of Things (IoT) di Pertanian*.

## Instalasi

```bash
git clone https://github.com/hanif2704/agriiot-absa.git
cd agriiot-absa
pip install -r requirements.txt
